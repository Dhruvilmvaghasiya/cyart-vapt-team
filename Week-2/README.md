# Week-2 VAPT Tasks
**Overview :-**

This repository documents the work completed during Week 2 of my VAPT internship. The focus of this week was to practically understand how vulnerabilities are identified, validated, and reported using standard penetration testing methodologies. The tasks were designed to simulate real-world assessment scenarios in a safe lab environment.


**Scope of Work :-**

The Week-2 tasks focused on:

- Reconnaissance and service enumeration

- Vulnerability scanning and validation

- Controlled exploitation using Metasploit

- Post-exploitation awareness and evidence handling

- SQL Injection simulation using DVWA

- Detection logging and remediation planning

- PTES-based reporting and non-technical communication

**Environment & Tools :-**  
1) Lab Environment

  - Attacker Machine: Kali Linux

  - Target Machines: Metasploitable 2, DVWA (TryHackMe lab)

2) Tools Used

- Nmap

- OpenVAS (Greenbone)

- Metasploit Framework

- sqlmap

- DVWA

- TryHackMe Labs

**Work Breakdown :-**

Part 1: Vulnerability Assessment

- Identified open services and vulnerabilities using scanning tools. Analyzed risk levels and prepared escalation communication.

Part 2: Reconnaissance

- Performed active and passive reconnaissance, documented exposed services, and summarized reconnaissance findings.

Part 3: Exploitation

- Validated vulnerabilities through a controlled exploit simulation using Apache Tomcat Manager. Generated a clear Proof of Concept.

Part 4: Post-Exploitation Awareness

- Verified access, collected minimal evidence, generated file hashes, and documented possible escalation paths without executing them.

Part 5: Enhanced Security Tasks

- Simulated SQL Injection on DVWA using sqlmap, logged vulnerabilities in PTES format, suggested remediation steps, and prepared both technical and non-technical reports.

**Documentation :-**

- All findings, screenshots, tables, and analysis are compiled in one consolidated PDF report.

- Escalation email and briefing content are maintained separately as required.

- Reporting follows PTES methodology and emphasizes ethical testing practices.

**Disclaimer :-**

All activities in this repository were performed strictly for educational purposes in authorized lab environments. No testing was conducted on real-world systems without permission. This work follows ethical hacking and responsible disclosure principles.
