# Week-3 VAPT Tasks
**Overview :-**

This repository documents the work completed during Week 3 of my VAPT internship. The focus of this week was on advanced exploitation techniques, web application penetration testing, post-exploitation analysis, structured reporting practices, and a capstone task demonstrating the full VAPT lifecycle. The activities were designed to strengthen both technical and reporting skills in a controlled lab environment.


**Scope of Work :-**

The Week-3 tasks focused on:

- Advanced exploitation concepts and exploit chaining (simulated)

- Proof-of-Concept (PoC) customization using Exploit-DB

- Web application penetration testing based on OWASP Top 10

- Manual and automated testing using industry tools

- Post-exploitation verification and evidence collection

- Chain-of-custody awareness and forensic-safe handling

- Professional reporting, visualization, and stakeholder communication

- Capstone task simulating a complete VAPT cycle


**Environment & Tools :-**  
1) Lab Environment

  - Attacker Machine: Kali Linux

  - Target Machines: Metasploitable 2, DVWA (Lab Environment)

2) Tools Used

- Metasploit Framework

- Burp Suite

- sqlmap

- Exploit-DB

- OpenVAS (for vulnerability detection and logging)

- Draw.io (attack path visualization)

- Google Docs (reporting and documentation)


**Work Breakdown :-**

Part 1: Advanced Exploitation Lab

- Simulated exploit chaining scenarios, customized Python-based PoCs from Exploit-DB, logged exploitation activities, documented findings, and prepared escalation communication.

Part 2: Web Application Testing Lab

- Tested DVWA for OWASP Top 10 vulnerabilities using manual and automated techniques, intercepted and manipulated requests with Burp Suite, validated SQL Injection and XSS, and summarized web testing results.

Part 3: Reporting Practice

- Created structured security reports including executive summaries, technical findings, remediation plans, findings tables, attack path visualization using Draw.io, and non-technical stakeholder briefings.

Part 4: Post-Exploitation and Evidence Handling

- Verified post-exploitation access, performed limited system enumeration, identified and preserved evidence, generated cryptographic hashes, and maintained a clear chain-of-custody record.

Part 5: Capstone Project – Full VAPT Cycle

- Simulated a full penetration testing workflow following PTES methodology, documented vulnerability detection using OpenVAS-style logs, referenced exploitation using Metasploit, suggested remediation steps, and prepared both technical and non-technical reports.


**Documentation :-**

- All findings, logs, tables, screenshots, and analysis are compiled into a single consolidated Week-3 VAPT report.

- Supporting artifacts such as screenshots and escalation email are organized part-wise in the repository.

- Reporting follows PTES methodology and emphasizes ethical testing, clarity, and responsible disclosure.


**Disclaimer :-**

All activities in this repository were performed strictly for educational and internship learning purposes within authorized lab environments. No testing was conducted on real-world systems without permission. This work adheres to ethical hacking standards and responsible disclosure principles.
